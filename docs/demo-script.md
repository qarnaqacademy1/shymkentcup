# Демо на 2–3 минуты

## Добавления 3.1

Для основного desktop-прогона после бюджета покажите Nazar Decision: цель, четыре действия, разрешение на 5 минут, затем журнал и Attention Map в настоящем отчёте. Срок в 5 минут нельзя показать истёкшим за 20 секунд — либо дождитесь реального срока, либо отдельно откройте /#demo с явной подписью «контрольный пример» и объясните эту границу. Не выдавайте его за запись студента.

Отдельный мобильный фрагмент: открыть #timer → выбрать шаблон/цель → 1 минута → старт → reload → завершить с заметкой и самоотметкой → синхронизировать → открыть source=mobile отчёт. Показать «Сайты не измеряются / бюджет не применяется», install-help Android/iPhone. Никаких заявлений о мониторинге других приложений. Реальный локальный браузерный тест этого пути выполнен; видео по-прежнему не записано.

Перед сдачей заполнить реальные имена команды в 12-слайдовой презентации 3.1, подтвердить Vercel team grant и проверить фактическую live-ссылку после публикации. Дедлайн по условиям — 9 ноября 2026, 23:59. Далее — базовый desktop-сценарий.

Подготовьте проект по README, отдельный профиль Chrome без личной истории и новый тестовый аккаунт. Правила: example.com, бюджет 0.05 минуты. Никаких seed/фиктивных измерений в основной базе.

| Время | Действие и пояснение |
| --- | --- |
| 0:00–0:20 | Лендинг и пустой кабинет: студент замечает отвлечение слишком поздно; аккаунт пока пуст. |
| 0:20–0:45 | Создать код, вставить в popup: один аккаунт, пароль расширению не передаётся. |
| 0:45–1:05 | example.com, цель «Разобрать один пример», 1 минута, старт и закрытие popup: снимок правил фиксирован. |
| 1:05–1:25 | Снова открыть popup после >3 секунд: бюджет достигнут. Показать предупреждение и при разрешении ОС уведомление. |
| 1:25–1:45 | «Этот сайт нужен для задачи», подождать: прошлые интервалы остаются, дальше исключение. |
| 1:45–2:05 | Пауза, продолжить, отметка выполнения и завершить: сначала локальное сохранение, потом API. |
| 2:05–2:35 | Обновить сайт, открыть настоящий отчёт, сверить числа и решения. Это время сайтов, не концентрация. |
| 2:35–2:55 | Показать правила и пояснение истории: импорт необязательный, посещения отдельно от времени, AI-ключи не нужны. |

Перед записью вручную проверьте уведомления, смену окон, idle, сон и восстановление по test-report.md. Автоматические тесты не называйте пользовательскими экспериментами.

## Запись

Настоящее видео здесь не заявляется готовым. Используйте встроенный рекордер, Clipchamp или OBS: отдельное тестовое окно, 1080p, голос по сценарию. Не захватывайте личные вкладки/историю и пароли. Один непрерывный реальный прогон, без подмены отчёта нарисованными числами. При ошибке исправьте и переснимите.

Экспорт MP4 2–3 минуты. Загрузку на YouTube/Google Drive и открытие доступа команда выполняет после проверки содержимого. Проверьте ссылку без входа, приложите к hackathon.kz вместе с репозиторием и pitch-deck.pdf. Ссылки и видео не выдуманы.
