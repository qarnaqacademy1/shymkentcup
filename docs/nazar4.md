# Nazar 4.0 — реализация и проверка

7 ноября 2026. Обновление существующего React/Express/Chrome MV3/PWA проекта с сохранением аккаунтов и формата прежних сессий.

## Реализовано

- **Smart Start:** первый экран кабинета, варианты 5/15/30/60/120 минут, своё время, цель, таймер и сохранение. Сервер резервирует время перед стартом; предел 240 минут общий для устройств аккаунта, день в Asia/Qyzylorda. Изменение пояса отчётов не сбрасывает предел. Для нового старта нужен сервер; начатую сессию можно завершить офлайн и отправить позже. Незавершённый план не возвращает резерв. Повтор UUID не списывает минуты повторно. Старые записи текущего дня учитываются при первом открытии бюджета; прежние клиенты необходимо обновить, они не резервируют новые планы.
- **Smart Break:** общий бюджет и лимиты доменов. 0 означает полный запрет, положительное значение — измеренное время домена за сессию. Поддомены включены. Chrome DNR перенаправляет новые открытия на `/#blocked?...`; открытые вкладки проверяет worker. Собственные адреса сайта и API исключены из перенаправления. Полный запрет работает и без активной сессии, пока расширение подключено. Достигнутые ограничения сохраняются после прерывания worker до новой сессии; обычное завершение снимает сессионные лимиты.
- **Focus Delay:** 15 секунд проверяются worker. Перезагрузка страницы не сокращает паузу. Возврат, разрешённые дополнительные 5 минут и Chat Pass записываются в журнал. Полный запрет не допускает исключений; дополнительное время по умолчанию выключено.
- **Chat Pass:** один раз на домен за сессию, до 10 минут и не дольше самой сессии. Только Instagram `/direct/` и Facebook `/messages/`. Новые сообщения и повторные запросы не продлевают пропуск. Лента/Reels разрешение не получают. При истечении срока разрешающее правило удаляется; перезапуск worker отзывает пропуск консервативно.
- **Donut Analytics:** интерактивные секторы и доступная с клавиатуры легенда; время, доля, лимит. Сегодня, последние 7/30 дней, конкретная сессия. Семь крупных категорий и «Другие». API читает весь период, а не страницу списка сессий. Только измеренные интервалы Chrome; мобильный таймер не создаёт измерений сайтов. Attention Map сохранена в подробностях как дополнительная карта событий.
- **Daily Report:** дата и сравнение с предыдущим днём, резервы, план сохранённых сессий, длительность, сайты, отвлекающее время, соблюдение лимитов, предупреждения, Chat Pass, завершённые сессии и самооценка. JSON и печать/PDF. Сайты точно делятся по локальной полуночи; план относится ко дню старта, длительность без пауз — целиком ко дню завершения записи. Неизвестное распределение пауз по дням не выдумывается.
- **Nazar AI:** защищённый серверный маршрут через AI SDK 7 / Vercel AI Gateway, добровольная отправка цели и агрегатов, лимит запросов и таймаут. Без конфигурации или при ошибке модели — явно подписанный «Анализ по правилам · без AI». Рекомендации не меняют настройки. Ключ и выбор модели остаются на сервере.

## API и данные

Все маршруты используют существующую авторизацию и изоляцию аккаунтов; защита cookie/Origin и Bearer сохранена.

| Маршрут | Назначение |
| --- | --- |
| GET `/api/plans` | Остаток суточного плана |
| POST `/api/plans` | `{id, goal, plannedMs, source}`; атомарное резервирование с идемпотентным повтором |
| GET `/api/analytics?from=...&to=...` | Сессии для аналитики за период до 32 дней |
| GET `/api/reports/daily?day=YYYY-MM-DD` | Отчёт дня |
| POST `/api/assistant` | `{goal, useAI, day?}`; анализ и планирование |

Настройки получили необязательные `siteLimits: [{domain, limitMs}]` и `allowExtraTime`. Старые payload валидируются без вымышленных полей и изменения канонического JSON. Миграция `202611070002_nazar4` добавляет только `StudyPlan` и `DailyBudget`, подготовлена для SQLite и PostgreSQL. Новые строки удаляются каскадно с аккаунтом; JSON-экспорт включает планы.

## Запуск и обновление

```powershell
npm ci
npm run db:generate
npm run db:migrate
npm run build
npm run dev
```

`db:migrate` сначала делает проверенную резервную копию SQLite. Для production PostgreSQL предусмотрена отдельная команда `npm run db:migrate:production`; пересоздавать базу или переносить аккаунты не требуется.

Расширение 0.4.0 требует обязательные `tabs`, `history`, `storage`, `idle`, `alarms`, `notifications`, `declarativeNetRequest` и доступ к HTTP/HTTPS сайтам для перенаправления. Доступ к истории предоставляется при установке/обновлении; обработка запускается по кнопке, отправка сводки требует отдельного согласия. При обновлении Chrome может запросить новые разрешения. Обновляйте файлы в прежней установленной папке и нажимайте «Обновить», сохраняя ID и очередь. `externally_connectable` ограничен точным адресом Nazar; страница блокировки не получает токены и историю.

Smart Start обнаруживает расширение через content script только на настроенном сайте Nazar. При совпадении аккаунтов можно начать, поставить на паузу, продолжить, завершить и синхронизировать Chrome-сессию с сайта. При отсутствии расширения доступен подписанный самостоятельный режим. Мост не раскрывает историю, credentials и чужие очереди; команды импорта истории через сайт запрещены. После обновления расширения перезагрузите открытую страницу Nazar.

Для AI задайте приватные `AI_GATEWAY_API_KEY` и `NAZAR_AI_MODEL` (существующий `provider/model` из актуального каталога Gateway). Vercel может использовать серверный OIDC. По умолчанию AI выключен в форме. Без ключа и модели платных запросов нет.

## Подтверждено

- TypeScript: успешно.
- 25 тестов: авторизация, CSRF, pairing, очередь, время, PWA, лимиты доменов, границы дней, суммы кольца, fallback, суточное резервирование с конкурентными запросами и изоляцией аккаунтов; мост сайта и расширения без раскрытия истории/credentials.
- Настоящий worker в Chrome-адаптере: DNR, перенаправление, серверный план, пауза 15 секунд, отказ раннему Chat Pass, один пропуск, фиксированный срок, отклонение ленты, отзыв по сроку, сохранение блокировки при перезапуске и отказ чужому origin.
- Собранные API, сайт и ZIP, регистрация, настройки, pairing: smoke успешно.
- Встроенный браузер и отдельная локальная база: вход → Smart Start → старт → самооценка/заметка → завершение → синхронизация → отчёт. Проверены честное пустое состояние аналитики, рекомендации без AI и сохранение полного запрета.

## Экспериментальное и непроверенное

- Chat Pass проверен как политика маршрутов. Реальные Instagram/Facebook после авторизации вручную не проверялись. Они могут менять маршруты и показывать часть контента внутри переписки; абсолютная изоляция контента не заявляется. TikTok Chat Pass не поддерживается.
- DNR и внешнее сообщение проверены адаптером. Установленное пользовательское расширение в Chrome в этом сеансе не обновлялось. Тайминг best-effort: сон и suspend могут задержать применение; большой разрыв консервативно прерывает сессию.
- Ответ настоящей AI-модели не проверялся: платный ключ не создавался. Серверный путь готов, fallback проверен.
- PWA не блокирует нативные мобильные приложения. Android-компонента нет.
- PostgreSQL-миграция `202611070002_nazar4` применена в существующей production-базе 7 ноября 2026: добавлены `DailyBudget`, `StudyPlan` и индекс без чтения содержимого аккаунтов и сессий. Код 4.0 запушен в `main` репозитория `qarnaqacademy1/shymkentcup`, коммит `c1553bd`. Публикация пока ожидает подтверждения CLI-входа Vercel: подключение MCP вернуло 403 для `qarnaq-academy1`, сохранённая CLI-авторизация отсутствует. Сведения о предыдущем публичном развёртывании относятся к 3.1.
- Прежние PDF/PPTX остаются материалами 3.1. Для демонстрации 4.0 используйте приложение и это описание. `#demo` содержит явно подписанные контрольные данные, не попадающие в аккаунт.
