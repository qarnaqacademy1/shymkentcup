# Nazar Mobile PWA

Это одно приложение React/Vite и тот же аккаунт/API. Desktop+Chrome extension измеряет сайты. PWA показывает отчёты/правила, помогает поставить цель и запустить самостоятельный таймер. Чужие вкладки и другие приложения на телефоне НЕ измеряются.

## Установка

- Android: откройте настоящий HTTPS Nazar в Chrome, нажмите «Установить Nazar». Если браузер предоставил beforeinstallprompt, будет системное предложение. Иначе: меню Chrome → «Установить приложение» / «Добавить на главный экран».
- iPhone: открыть в Safari → «Поделиться» → «На экран Домой». Универсальный автоматический prompt не обещается.
- Локальная проверка: `npm run build`, `npm start`, http://localhost:3001. Manifest и SW обслуживаются только собранной версией; Vite dev не регистрирует production SW. Для доступа с телефона к компьютеру localhost телефона не подходит — нужна доступная HTTPS публикация.

Manifest: `/manifest.webmanifest`, standalone, scope /, start_url /#overview, русский язык, иконки 192/512, отдельная maskable-512 и apple-180, safe-area на мобильном. Ширина 390 px проверена в браузере, scrollWidth равен viewport, ошибок консоли не обнаружено.

## Таймер и данные

Остаток по timestamp, а не числу тиков. Активный таймер сохраняется под ключом с id владельца в localStorage, переживает reload/возврат в аккаунт. Пауза переносит deadline. Завершение сохраняет note/taskDone и source=mobile, интервалы сайтов запрещены серверной схемой. Очередь отправляется кнопкой «Синхронизировать с аккаунтом» после восстановления сети, до подтверждения остаётся на устройстве. Сервер требует совпадение ownerId очереди с проверенной cookie-сессией; при переключении аккаунта/истечении cookie результат не отправляется другому владельцу.

Мобильные сессии видны отдельно от Chrome-сессий. Они не входят в KPI соблюдения бюджета сайтов и не увеличивают учтённое время сайтов. Заметки и самоотметка — слова пользователя, не объективная продуктивность. Недельная цель добровольная, без рейтингов/серий.

## Офлайн и приватность

SW кеширует только явный список публичных ресурсов и файлы `/assets` с расширением js/css/woff2. API, отчёты, ZIP, авторизованный HTML и токены не кладутся в кеш. Навигация при отсутствии сети показывает публичную offline.html; приватная история не доступна из общего кеша. Уже открытый таймер продолжает работать по timestamps; после полного offline-reload доступна справка, а восстановление таймера происходит после возвращения сети и входа в тот же аккаунт. Это минимальная офлайн-поддержка, не обещание полноценного offline кабинета.

## Что действительно проверено

Локальный собранный сайт: регистрация, старт мобильной сессии, reload с корректным остатком, завершение с заметкой/самоотметкой, синхронизация и отчёт с source=mobile; install-help Android/iPhone, 390 px без горизонтального скролла. Unit-проверка manifest, размеров PNG и запрета private cache. Production HTTPS: https://nazar-orpin.vercel.app . Публичные manifest, service worker, offline.html и 192/512/maskable icons проверены по HTTP. Физическая установка на Android/iPhone ещё требует проверки на устройствах; она не заявляется выполненной.
