## Неподтверждённый ручной Chrome-прогон

Распакованное расширение в настоящий профиль Chrome автоматически не устанавливалось. Для установки в отдельный тестовый профиль запрошено отдельное разрешение; до подтверждения действие не выполняется. Веб-сайт проверен отдельно, полного ручного пути Chrome → API → отчёт пока нет. Уведомления ОС, реальный getVisits/isLocal, блокировка/сон устройства, остановка worker самим Chrome и два физических окна требуют ручного прогона.

Шаги для проверки по 12 пунктам задания:

1. Новый профиль и аккаунт, установить dist по README, подключить. Старт 2 минуты на example.com, закрыть popup на 10 секунд, открыть: сессия идёт, время не сбрасывается.
2. Второе окно Chrome: чередовать активные окна, менять домен в той же вкладке; итог не должен превышать стеновое время сессии.
3. Пауза на 10 секунд: оба счётчика стоят, после продолжения дедлайн сдвинут. Другое приложение/idle 120 секунд/блокировка останавливают сайты, план сессии продолжает идти.
4. Сон >45 секунд и перезапуск браузера/worker: статус interrupted, подтверждённый результат, разрыв не начислен. Поздний alarm не начисляет после дедлайна. Проверить и короткий сон: погрешность возможна и документирована.
5. example.com в списке, бюджет 3 секунды, после предупреждения разрешить сайт для задачи; отвлекающее время перестаёт расти, старый интервал остаётся.
6. В тестовом профиле создать известные посещения, импортировать дважды; число не удваивается. Сверить локальные visitTime в периоде, не общий visitCount. При достижении лимита видна неполнота.

8. Остановить API, закончить: результат в очереди. Восстановить API, синхронизировать дважды: один отчёт.
9. С очередью A отключиться, подключить B: очередь A не отправляется. Снова A: очередь уходит. Проверить чтение чужого id через API (автоматически проверено).

## Оставшиеся ограничения

Публичного deployment/рабочего внешнего URL и настоящего видео нет. Есть воспроизводимый локальный запуск и сценарий записи. Состав команды и пользовательские исследования не выдуманы. MVP не прошёл нагрузочные, межустройственные и длительные полевые испытания; нет восстановления пароля, email verification, AI и платежей. Idle и консервативное прерывание worker ограничивают непрерывность/точность. Подробности: architecture.md и README.

PDF-экспорт Artifact Tool в этой Windows-сборке завершился ошибкой отсутствующего Helvetica-модуля; финальный PDF создан ReportLab из проверенных PNG слайдов. PPTX создан Artifact Tool и остаётся редактируемым. Проверка в самом PowerPoint не заявляется выполненной.
